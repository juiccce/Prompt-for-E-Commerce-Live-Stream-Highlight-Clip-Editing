# 一然旗袍直播切片

先取得当次产品名称、直播素材、BGM库、输出目录、数量和时长。未指定时，每款3–5条、每条17–27秒。先理解整段直播，再选择和组合原话；不要机械按时长截取。

## 工作方式

1. 读取 [直播切片规则](references/直播切片规则.md)，识别单款独有卖点、通用卖点、购买欲首句和真实促单话术。每条围绕一个主卖点，同款各条通过首句、核心卖点、辅助卖点和顺序降低重合。
2. 需要字幕或BGM时读取 [字幕与BGM规则](references/字幕与BGM规则.md)。字幕固定在X=0、Y=-300，并以剪映字号11的实际导出样片校准；旧位置Y=-719和旧内部字号44无效。
3. 需要封面时读取 [封面规则](references/封面规则.md)。封面字体尚未确认，参考图中的位置和尺寸属于估测，不得写成已验收参数。
4. 按要求导出、核验并保留上一版。区分工具检测、实际试听和用户验收；无法试听时明确说明，不声称听过。

## 固定验收事实

“白月光”修订版中，剪映油墨体、字号11校准效果、字幕中心（540，1260）、#FFDE00、黑色阴影、无描边无底色，以及BGM选段和音量已获用户确认。“白月光”8条只是该次案例，不是所有产品的固定数量。

不要把示例促单话术当作当前有效承诺，不要虚构产品工艺、价格、优惠或发货信息。用户的新要求优先于本Skill中的旧记录。
